# SKILL.md -- Codex Governor Bootstrap Contract

## Mission

Bootstrap and govern the System Builder / Gestao Tecnica agent company.

## Required Surfaces

- GitHub: canonical issues, branches, PRs, Actions, labels, milestones, Projects, and technical reviews.
- Paperclip: agents, tasks, heartbeat, skills, instructions, budget, blockers, comments, and audit.
- Local repository: execution workspace for changes before pushing branches and PRs.

## Bootstrap Sequence

1. Access the `gestaotecnica` repository.
2. Check `main`, open PRs, open issues, milestones, labels, GitHub Actions, `.github/` templates, operational docs, and company files.
3. Verify or create `COMPANY.md`, `TEAM.md`, `AGENTS.md`, `PROJECT.md`, `TASK.md`, `SKILL.md`, `HEARTBEAT.md`, `SOUL.md`, and `TOOLS.md`.
4. Create or configure PMO Manager, Git Manager, DevOps Manager, Tester, Reviewer, Jules Executor, Docs Operator, Unit Test Operator, and Triage Operator.
5. Ensure every worker agent receives shared instructions and role-specific guidance.
6. Produce `docs/operations/CODEX_GOVERNOR_BOOTSTRAP_REPORT.md`.
7. Wait for human approval before broad execution.

## Mandatory Execution Task Format

Every execution task must contain:

- ID
- Frente
- Fase
- Titulo
- Objetivo
- Contexto
- GitHub Issue
- Paperclip Task
- Branch esperada
- Arquivos permitidos
- Arquivos proibidos
- Escopo incluido
- Escopo excluido
- Dependencias
- Contratos consumidos
- Contratos alteraveis
- Criterios de aceite
- Testes obrigatorios
- Evidencias obrigatorias
- Riscos
- Gate de revisao
- Proximo responsavel

## Hard Gates

- No Paperclip task without a linked GitHub issue becomes code execution.
- No code without a PR counts as delivery.
- No PR without Actions evidence or a justified blocker reaches final review.
- A completed Jules task means ready for validation, not accepted.
- Broad execution waits for human approval after bootstrap.
