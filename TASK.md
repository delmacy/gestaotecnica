# GitHub-First Pilot Task

Run one small System Builder / Gestao Tecnica task through the complete operating loop:

1. Codex defines scope and gate.
2. PMO creates/links the GitHub issue.
3. Jules or OpenCode implements on a branch.
4. PR opens with required evidence.
5. Actions run.
6. Tester and Reviewer validate.
7. Codex approves, requests changes, closes, or escalates.
