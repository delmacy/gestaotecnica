# Arquivo histórico

Esta pasta deve guardar documentos antigos, auditorias, planos substituídos e decisões que não são mais fonte principal de implementação.

## Regra

Todo documento arquivado deve receber no topo:

```md
> Documento histórico. Não usar como fonte principal de implementação.
> Fonte atual: docs/00-current/
```

## Observação

Não apagar documentos antigos sem uma fase específica de limpeza documental.
