# System Builder Documentation

Esta pasta contém a documentação central do projeto System Builder.

A documentação deve passar a ser a fonte de verdade operacional do projeto.

O princípio obrigatório é:
1. Markdown primeiro.
2. Contrato depois.
3. Código por último.

Navegue pelos módulos e leia as instruções em `DEVELOPMENT_RULES.md` para entender como contribuir.
