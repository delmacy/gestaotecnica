# Constraints

- PR must target main.
- Do not broaden scope beyond the task objective.
- Do not weaken or delete existing tests.
- Do not change database schema or migrations unless explicitly allowed.
- Prefer evidence from real repository commands and GitHub state over assumptions.
- If external access is unavailable, document the blocker precisely and stop.
- Forbidden scope: runtime behavior changes
- Forbidden scope: database schema
- Forbidden scope: migrations
