# Acceptance Criteria

- Implementation stays inside allowed files for this task.
- Real-data behavior is distinguishable from synthetic/demo behavior in code and UI labels.
- Focused tests or documented validation evidence are included in the PR.
- PR body includes base SHA, commands run, and real-data evidence or exact blocker.
- No new explicit TypeScript `any` appears in modified source or tests unless the task is explicitly a no-any scanner test containing quoted forbidden-pattern fixtures.
