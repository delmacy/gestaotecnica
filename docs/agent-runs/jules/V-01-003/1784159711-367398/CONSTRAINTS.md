# Constraints

- PR must target main.
- Implement only this task.
- Keep changes small and reviewable.
- Do not weaken or delete existing tests.
- Prefer existing contracts and local patterns over new abstraction layers.
- If validation fails for unrelated baseline reasons, document exact evidence and stop instead of broadening scope.
- Open a GitHub PR against main when done.
- Forbidden scope: database schema
- Forbidden scope: migrations
- Forbidden scope: UI code
