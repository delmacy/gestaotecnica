# Process Improvement Proposals

As propostas de melhoria seguem a mesma lógica ontológica do Process Candidate, mas aplicam-se a processos **já existentes**.

## Template de Proposta (Formato Padrão)
Sempre que um agente ou humano propõe uma melhoria operacional, o sistema exigirá:
1. Processo afetado.
2. Gargalo observado.
3. Evidência concreta.
4. Causa provável.
5. Proposta de alteração (nova action, nova rule).
6. Impacto esperado.
7. Riscos e Mitigações.
8. Necessidade de Decisão Humana.

Nenhuma sugestão ocorre solta; o sistema formaliza a intenção de mudança.
