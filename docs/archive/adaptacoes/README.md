# Adaptacoes

Adaptacoes sao pacotes de configuracao que ensinam a plataforma a operar como
um cliente ou setor especifico.

Uma adaptacao pode definir:

- terminologia;
- tipos;
- papeis;
- workflows;
- filas;
- templates;
- regras locais;
- configuracao de legado.

O core nao deve conhecer detalhes da adaptacao.
