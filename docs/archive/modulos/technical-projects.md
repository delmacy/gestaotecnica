# Modulo: Technical Projects

## Configuracao

Projetos ficam em `technical_projects`.

Use a porta publica `src/modules/technical-projects` para forms, listas, actions e queries. A rota `/technical-projects` nao deve importar diretamente o agrupador historico `strategy`.

## Adaptacao por cliente

Configure sponsor, escopo, datas, status, marcos e relacao com aquisicoes.
