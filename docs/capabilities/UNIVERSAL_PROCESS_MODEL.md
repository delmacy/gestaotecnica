# Universal Process Model

## Objetivo
Fornecer verbos de referência para comparar processos observados sem impor um workflow rígido.

## Macrofluxo
capturar → qualificar → priorizar → aprovar → planejar → agendar → alocar → executar → evidenciar → validar → entregar → cobrar/receber → documentar → auditar → medir → melhorar.

## Campos de um processo universal
Intenção, gatilho, entrada, saída, atores, precondições, estados, decisões, exceções, evidências, métricas, eventos e capabilities participantes.

## Regras de uso
- Uma organização pode pular, repetir ou adaptar etapas.
- Casos adaptativos não devem ser forçados em sequência fixa.
- Toda mudança vem de Process Mirroring e validação.
- Publicação exige versão e aprovação humana.

## Critério de pronto
O processo é explicável por usuários, possui começo/fim ou condição de continuidade, cobre exceções e aponta eventos e evidências.
