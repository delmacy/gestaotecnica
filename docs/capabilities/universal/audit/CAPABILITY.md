# Capability — audit

## Core business
Preservar eventos, evidências e revisões rastreáveis.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | control |
| Entidades principais | AuditEvent, Evidence, AuditReview |
| Estados principais | recorded, under_review, accepted, disputed |
| Processos principais | record event; investigate; attest |
| Relações | governance, all operational capabilities |
| Estado documental | review; ainda não autoriza implementação |

## Exemplo genérico
Uma alteração registra ator, antes/depois e justificativa.

## Fora de escopo
Especialização setorial, detalhes de cliente, implementação técnica e absorção silenciosa das capabilities relacionadas.

## Critérios de aceite
Fronteira compreensível; entidades e estados coerentes; processos e eventos rastreáveis; regras e UI revisadas; relações e gaps declarados.
