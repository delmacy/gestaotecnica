# UI Contract — audit

## Superfícies mínimas
Lista/board, detalhe, criação ou comando permitido, filtros, histórico e relações com governance, all operational capabilities.

## Estados obrigatórios
Vazio, carregando, erro, acesso negado, sucesso e os estados de domínio: recorded, under_review, accepted, disputed.

## Regras
A interface mostra workspace ativo, ações disponíveis por papel, confirmação para ações críticas, feedback e trilha. UI não inventa regra nem esconde falta de autorização.

## Exemplo
Uma alteração registra ator, antes/depois e justificativa.

## Critério de pronto
Persona, rota, escopo, dados, comandos, estados, permissões, auditoria e teste E2E esperado estão documentados.
