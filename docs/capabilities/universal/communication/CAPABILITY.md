# Capability — communication

## Core business
Gerenciar mensagens, conversas, canais e notificações.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | information |
| Entidades principais | Conversation, Message, Channel, Template |
| Estados principais | queued, sent, delivered, failed, read |
| Processos principais | send message; notify; track conversation |
| Relações | customers, requests, integrations |
| Estado documental | review; ainda não autoriza implementação |

## Exemplo genérico
Uma notificação de agendamento registra entrega.

## Fora de escopo
Especialização setorial, detalhes de cliente, implementação técnica e absorção silenciosa das capabilities relacionadas.

## Critérios de aceite
Fronteira compreensível; entidades e estados coerentes; processos e eventos rastreáveis; regras e UI revisadas; relações e gaps declarados.
