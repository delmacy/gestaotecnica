# Capability — compliance

## Core business
Gerenciar políticas, controles, achados e remediação.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | control |
| Entidades principais | Policy, Control, Finding, Remediation |
| Estados principais | planned, compliant, non_compliant, remediated |
| Processos principais | define control; assess; remediate |
| Relações | governance, audit |
| Estado documental | review; ainda não autoriza implementação |

## Exemplo genérico
Um controle falho gera achado e plano de remediação.

## Fora de escopo
Especialização setorial, detalhes de cliente, implementação técnica e absorção silenciosa das capabilities relacionadas.

## Critérios de aceite
Fronteira compreensível; entidades e estados coerentes; processos e eventos rastreáveis; regras e UI revisadas; relações e gaps declarados.
