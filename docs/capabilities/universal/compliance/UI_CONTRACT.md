# UI Contract — compliance

## Superfícies mínimas
Lista/board, detalhe, criação ou comando permitido, filtros, histórico e relações com governance, audit.

## Estados obrigatórios
Vazio, carregando, erro, acesso negado, sucesso e os estados de domínio: planned, compliant, non_compliant, remediated.

## Regras
A interface mostra workspace ativo, ações disponíveis por papel, confirmação para ações críticas, feedback e trilha. UI não inventa regra nem esconde falta de autorização.

## Exemplo
Um controle falho gera achado e plano de remediação.

## Critério de pronto
Persona, rota, escopo, dados, comandos, estados, permissões, auditoria e teste E2E esperado estão documentados.
