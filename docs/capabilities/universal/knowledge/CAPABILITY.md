# Capability — knowledge

## Core business
Capturar, revisar e publicar conhecimento operacional.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | information |
| Entidades principais | KnowledgeArticle, Category, Revision |
| Estados principais | draft, review, published, retired |
| Processos principais | capture knowledge; review; publish |
| Relações | enablement, documents |
| Estado documental | review; ainda não autoriza implementação |

## Exemplo genérico
Um procedimento validado vira artigo por papel.

## Fora de escopo
Especialização setorial, detalhes de cliente, implementação técnica e absorção silenciosa das capabilities relacionadas.

## Critérios de aceite
Fronteira compreensível; entidades e estados coerentes; processos e eventos rastreáveis; regras e UI revisadas; relações e gaps declarados.
