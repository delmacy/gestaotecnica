# Capability — procurement

## Core business
Gerenciar requisições, cotações, pedidos e recebimento.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | commercial |
| Entidades principais | PurchaseRequest, Quote, PurchaseOrder, Receipt |
| Estados principais | requested, sourcing, approved, ordered, received |
| Processos principais | request purchase; quote; approve; receive |
| Relações | providers, approvals, inventory, finance |
| Estado documental | review; ainda não autoriza implementação |

## Exemplo genérico
Uma requisição aprovada compara três cotações.

## Fora de escopo
Especialização setorial, detalhes de cliente, implementação técnica e absorção silenciosa das capabilities relacionadas.

## Critérios de aceite
Fronteira compreensível; entidades e estados coerentes; processos e eventos rastreáveis; regras e UI revisadas; relações e gaps declarados.
