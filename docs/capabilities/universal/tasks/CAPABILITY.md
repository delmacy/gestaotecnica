# Capability — tasks

## Core business
Organizar unidades atribuíveis de trabalho e dependências.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | work-management |
| Entidades principais | Task, Checklist, Assignment, Dependency |
| Estados principais | backlog, ready, in_progress, blocked, review, done |
| Processos principais | create task; assign; execute; review |
| Relações | people, cases, work_orders |
| Estado documental | review; ainda não autoriza implementação |

## Exemplo genérico
Uma tarefa bloqueada aguarda documento antes da revisão.

## Fora de escopo
Especialização setorial, detalhes de cliente, implementação técnica e absorção silenciosa das capabilities relacionadas.

## Critérios de aceite
Fronteira compreensível; entidades e estados coerentes; processos e eventos rastreáveis; regras e UI revisadas; relações e gaps declarados.
