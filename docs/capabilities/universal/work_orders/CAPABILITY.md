# Capability — work_orders

## Core business
Planejar, executar, evidenciar e validar serviços.

## Contrato resumido
| Campo | Valor |
|---|---|
| Categoria | work-management |
| Entidades principais | WorkOrder, Execution, Evidence, Validation |
| Estados principais | draft, planned, executing, validation, closed |
| Processos principais | issue work order; execute; validate; close |
| Relações | requests, tasks, assets, audit |
| Estado documental | review; ainda não autoriza implementação |

Uma ordem exige fotos e validação do supervisor.

## Critérios de aceite
