# Platform Error Next.js Response Adapter

ID: PKG-PLATFORM-ERROR-NEXT-RESPONSE-ADAPTER-001
Module: platform-errors
Status: stable

## Overview

This adapter provides functions to transform canonical `PlatformErrorEnvelope` objects into Next.js `NextResponse` objects. It ensures that the HTTP status code, response body, and headers are consistent with the platform's error handling policies.

## API

### `toNextPlatformErrorResponse(error: PlatformErrorEnvelope): NextResponse`

Transforms a validated `PlatformErrorEnvelope` into a `NextResponse`.

- **Status Code**: Determined by `mapPlatformErrorToHttpStatus`.
- **Body**: Generated by `toPlatformErrorHttpBody`.
- **Headers**:
    - `Content-Type: application/json`
    - `X-Correlation-Id`: Included if `error.correlationId` is present and safe (no CRLF).

### `toNextUnknownErrorResponse(error: unknown, context: PlatformErrorContext): NextResponse`

A convenience function for handling `unknown` errors in API routes.

1. Sanitizes the input using `sanitizeUnknownError`.
2. Creates a `PlatformErrorEnvelope` with category `unexpected`.
3. Returns the result of `toNextPlatformErrorResponse`.

## Security Policy

- **No Internal Exposure**: The adapter uses `toPlatformErrorHttpBody` which redacts technical details, stack traces, and internal metadata.
- **Header Safety**: `X-Correlation-Id` is checked for CRLF injection.
- **Purity**: The adapter is a thin wrapper around pure mapping functions.
