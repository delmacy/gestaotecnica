# Instruções - doc

## Responsabilidade
Módulo de documentação.

Responsável por documentos internos, instruções por módulo, versionamento textual, rastreabilidade de decisões, documentação como fonte de verdade e manutenção dos arquivos Markdown.

Esse módulo representa o trabalho do próprio Jules Doc.

## O que pode fazer
- Manter e evoluir a documentação estrutural.

## O que não pode fazer
- Implementar código fora da gestão de documentação.
