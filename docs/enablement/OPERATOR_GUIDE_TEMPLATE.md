# Operator Guide Template

## Objetivo
Padronizar guias operacionais por papel e cenário.

## Campos e entidades obrigatórios
papel, objetivo, quando usar, precondições, permissões, passos numerados, decisões, exceções, evidências, proibições, escalonamento, métricas, versão.

## Processo de uso
Preencher a partir de processo validado → revisar com governance → testar em cenário real/simulado → corrigir → publicar.

## Critérios de aceite
Guia cobre cenário normal e exceção; usa linguagem do operador; ações e limites são inequívocos; evidência esperada está clara.

## Exemplo aplicado
Guia de triagem explica dados mínimos, matriz de prioridade, quando pedir complemento e quando escalar.

## Riscos e anti-padrões
Copiar documentação técnica; omitir tarefas proibidas; guia sem versão; instruções longas sem decisão clara.
