# Capability Map

## Finalidade
Mostrar capacidades existentes, necessárias e suas relações.

## Campos obrigatórios
capability, categoria, responsável, maturidade, workspaces, dependências, gaps e evidências

## Exemplo
| Capability|Responsável|Maturidade|Dependências|Gap |
| ---|---|---|---|--- |
| requests|Operações|em validação|customers, communication|triagem informal |

## Relação com Process Mirroring e Capabilities
Matches vindos do espelho confirmam capacidades usadas; o catálogo fornece definição e limites.

## Critérios de pronto
Escopo e versão definidos; responsáveis participaram; fontes e suposições estão registradas; relações e gaps são rastreáveis; mapa possui próximo passo.
