# System Data Map

## Finalidade
Mapear onde dados nascem, circulam, são transformados e governados.

## Campos obrigatórios
dado, entidade, fonte de verdade, sistema, formato, owner, sensibilidade, consumidores, retenção e gaps

## Exemplo
| Dado|Fonte|Owner|Sensibilidade|Gap |
| ---|---|---|---|--- |
| evidência de execução|work_order|Operações|interna|fica em canal pessoal |

## Relação com Process Mirroring e Capabilities
Fontes observadas revelam planilhas e sistemas; entities das capabilities dão significado e fronteira.

## Critérios de pronto
Escopo e versão definidos; responsáveis participaram; fontes e suposições estão registradas; relações e gaps são rastreáveis; mapa possui próximo passo.
