# Value Stream Map

## Finalidade
Explicar como capacidades combinadas geram valor ponta a ponta.

## Campos obrigatórios
stream, trigger, stakeholder, etapas, capabilities, lead time, espera, saída, métrica e riscos

## Exemplo
| Stream|Trigger|Capabilities|Saída|Métrica |
| ---|---|---|---|--- |
| Atender demanda|mensagem recebida|requests, work_orders, audit|serviço validado|tempo até fechamento |

## Relação com Process Mirroring e Capabilities
Process Mirroring fornece etapas e atrasos reais; capabilities mostram os blocos reutilizáveis.

## Critérios de pronto
Escopo e versão definidos; responsáveis participaram; fontes e suposições estão registradas; relações e gaps são rastreáveis; mapa possui próximo passo.
