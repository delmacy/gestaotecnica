# Módulos

Índice de módulos reutilizáveis e seus contratos.

Durante a migração, a documentação pode permanecer nos diretórios de domínio existentes, como `capabilities/`, `runtime/`, `workflow/`, `integrations/` e `ui/`.

## Regra

Cada módulo descreve:

- responsabilidade universal;
- entidades e contratos;
- eventos;
- permissões;
- superfícies de UI;
- pontos de configuração por adaptação.

O módulo não mantém roadmap global nem status de fase. Evoluções executáveis são registradas em `../phases/`.
