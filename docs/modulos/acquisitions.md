# Modulo: Acquisitions

## Configuracao

Necessidades ficam em `acquisition_needs`.

Use a porta publica `src/modules/acquisitions` para forms, listas, actions e queries. A rota `/acquisitions` nao deve importar diretamente o agrupador historico `strategy`.

## Adaptacao por cliente

Configure justificativa, quantidade, custo, protocolo e documentos administrativos.
