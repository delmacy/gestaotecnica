# Mirroring Model

Process Mirroring é a camada do System Builder que captura como uma organização realmente trabalha hoje, antes de impor fluxos, automações ou padrões teóricos.

## Pipeline
Capture Sources → Build As-Is Mirror → Identify Work Units → Extract Patterns → Match Capabilities → Compare with Reference Models → Detect Gaps → Adapt to Reality → Validate with Client → Generate Builder Package.

## Entidades
ObservedProcess, ObservedStep, ObservedActor, ObservedRole, ObservedTool, ObservedSystem, ObservedArtifact, ObservedDocument, ObservedSpreadsheet, ObservedCommunication, ObservedDecision, ObservedException, ObservedRule, ObservedDataField, ObservedEvidence, ObservedPainPoint, ObservedWorkaround, ObservedControl, ObservedRisk, ObservedMetric, ExtractedPattern, ProcessVariant, ReferencePattern, CapabilityMatch, ProcessGap, AdaptationProposal, ValidatedProcess e BuilderPackage.

## Regra
O espelho inicial descreve o processo real, inclusive atalhos, exceções e controles paralelos; melhoria vem depois da validação.
