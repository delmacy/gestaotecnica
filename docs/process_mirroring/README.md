# process_mirroring

## Propósito
Capturar como a organização realmente trabalha antes de impor automação.

## Regra operacional
Toda mudança nasce em TASKS.md, respeita DECISIONS.md, atualiza WORK_BOARD.md e produz contrato antes de código.

## Escopo
Fontes, observações, variantes, padrões, gaps, adaptações e validação.
