# Collection Gaps - Technical Service Intake (Pilot)

| gap_id | description | impact | required_source | owner_or_role | risk_if_missing | next_action | status |
|---|---|---|---|---|---|---|---|
| GAP-001 | Falta de print real anonimizado de cliente | Não sabemos que tipo de linguagem ou mídias são efetivamente enviados. | Exemplo de conversa WhatsApp anonimizada | Dispatcher | Criar interface de request incompatível com a forma de uso do cliente | Solicitar dump anonimizado via `REAL_SOURCE_REQUEST_PACK.md` | pending |
| GAP-002 | Falta de linha real da planilha de controle | Não sabemos quais colunas (dados) o atendente prioriza na triagem que não cabem no sistema oficial. | Exporte de 5 linhas da planilha atual (anonimizadas) | Dispatcher | Omitir campos críticos na construção do novo formulário | Solicitar exporte via `REAL_SOURCE_REQUEST_PACK.md` | pending |
| GAP-003 | Falta de exemplo real de OS no sistema | Desconhecemos os campos obrigatórios do sistema legado e como os dados são organizados na UI. | Print da tela de OS cadastrada no sistema atual | Dispatcher/Supervisor | Incompatibilidade na modelagem de Work Orders | Solicitar print borrado via `REAL_SOURCE_REQUEST_PACK.md` | pending |
| GAP-004 | Falta de validação com o técnico | Não sabemos se o técnico recebe a OS pelo sistema, se printa tela, ou se só atua por mensagem de voz. | Entrevista rápida ou print da tela do técnico | Technician | Desenhar interface web para quem só usa celular offline em campo | Preencher `INTERVIEW_CAPTURE_FORM.md` | pending |
| GAP-005 | Falta de validação com supervisor | Desconhecemos os critérios exatos para aprovar ou rejeitar uma foto de evidência. | Observação direta ou entrevista com supervisor | Supervisor | Omitir a capability de "audit" ou de "governance" e permitir auto-aprovação indevida | Preencher `INTERVIEW_CAPTURE_FORM.md` | pending |
| GAP-006 | Falta de consentimento formal registrado | O uso de dados (mesmo sintéticos baseados em observações) para o piloto requer ciência dos donos do processo. | E-mail ou aceite em documento do piloto | Cliente/Gestor do processo | Violar política de dados (projeto parado) | Assinar `CONSENT_TEMPLATE.md` | pending |
