# Termo de Consentimento para Uso de Fontes Reais

**Processo Piloto:** Technical Service Intake (Entrada de Chamado Técnico)
**Responsável pelo Processo:** [Nome do Responsável / PO / Cliente]

## 1. Objetivo da Coleta
Este termo autoriza a coleta e análise de amostras de dados operacionais reais (anonimizados) para suportar a modelagem de processos do projeto "Process Mirroring". O objetivo é entender a realidade do fluxo de trabalho ("As-Is"), identificar lacunas em relação ao sistema atual e garantir que os contratos de software propostos atendam ao dia a dia da operação.

## 2. Limitação de Uso
**Importante:** Este consentimento autoriza **apenas** a análise documental do piloto para refinar o desenho da arquitetura e UI.
**ESTE TERMO NÃO AUTORIZA:**
- A utilização dos dados em ambientes de produção.
- A inserção dos dados reais no código-fonte, banco de dados ou arquivos técnicos do repositório.
- A publicação externa, compartilhamento ou uso comercial dos dados.

## 3. Tipos de Fonte Permitidos
Conforme detalhado no pacote de solicitação, são permitidos o envio de:
- Exemplos textuais de chamados/mensagens ou prints anonimizados;
- Recortes parciais e anonimizados de planilhas de controle interno ("Shadow IT");
- Prints borrados ou anonimizados das telas do sistema oficial atual;
- Respostas a roteiros de entrevistas.

## 4. Proibição de Dados Sensíveis e Regras de Anonimização
O signatário compromete-se a garantir que as fontes fornecidas foram devidamente anonimizadas e **NÃO CONTÊM**:
- Nomes completos de clientes, parceiros ou funcionários (além do estritamente necessário e consentido internamente);
- Documentos de identificação (CPF, RG, CNPJ);
- Dados de contato reais (telefone, e-mail pessoal);
- Endereços físicos reais completos;
- Matrículas, placas de veículos, dados financeiros ou senhas;
- Fotos de rostos de pessoas.

Para garantir a limpeza adequada, os dados devem ter sido tratados conforme os parâmetros definidos no `ANONYMIZATION_GUIDE.md`.

## 5. Aceite Formal

Declaro estar ciente das restrições e do objetivo exclusivo de uso documental das informações a serem fornecidas pela minha equipe ou por mim mesmo, isentando os dados de qualquer conteúdo de PII ou sensível não mascarado. Autorizo a equipe de análise a referenciar essas fontes anonimizadas nos artefatos de arquitetura do piloto.
