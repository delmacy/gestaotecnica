# Chamados Anonimizados

## Chamado 1

Origem:
WhatsApp

Mensagem recebida:
"Bom dia, a internet da Unidade X está caindo toda hora. O roteador tá com a luz vermelha."

Dados que vieram completos:
- Unidade (Unidade X)
- Problema reportado (internet caindo / luz vermelha)

Dados que faltaram:
- Localização exata dentro da Unidade (ex: andar, sala)
- Número de patrimônio do equipamento Z

Houve foto inicial?
não

O atendente precisou perguntar algo?
sim — "Qual andar e qual é o patrimônio do equipamento que está com a luz vermelha?"

Virou OS?
sim

Observação:
O cliente demorou 1 hora para responder, o que atrasou a triagem.

## Chamado 2

Origem:
Telefone

Mensagem recebida:
"O Equipamento Z principal da sala de reunião não liga. Cliente A relatou que cheirou a queimado."

Dados que vieram completos:
- Problema (não liga / cheiro de queimado)
- Local (Sala de reunião)

Dados que faltaram:
- Qual Equipamento Z (tem 3 na sala)

Houve foto inicial?
não

O atendente precisou perguntar algo?
sim — "Qual é a etiqueta de patrimônio ou modelo do equipamento que não liga?"

Virou OS?
sim

Observação:
Foi classificado com urgência Alta devido ao risco relatado (cheiro de queimado).

## Chamado 3

Origem:
E-mail

Mensagem recebida:
"Solicito troca do cabo de rede no Local Y, está com mau contato."

Dados que vieram completos:
- Local (Local Y)
- Problema (cabo com mau contato)

Dados que faltaram:
- Não informou qual ponto de rede ou quem será o usuário afetado.

Houve foto inicial?
não

O atendente precisou perguntar algo?
sim — "Qual é o número do ponto de rede na parede?"

Virou OS?
sim

Observação:
Processo padrão, baixa urgência.
