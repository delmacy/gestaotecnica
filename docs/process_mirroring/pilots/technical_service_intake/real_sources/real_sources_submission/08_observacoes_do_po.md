# Observações do Product Owner (PO)

- Os dados fornecidos neste pacote foram cuidadosamente anonimizados conforme as regras do guia.
- O maior gargalo apontado é a dependência do WhatsApp não formalizado para entrada e triagem de dados antes de virar uma Ordem de Serviço.
- As respostas mostram claramente as dores do Dispatcher (Nível 1) na transição da informação para o Técnico (Nível 2).
- Os sistemas atuais (planilhas vs. ERP legado) não conversam, forçando a duplicidade de preenchimento.
- Como PO, reforço que a futura implementação não deve repetir esses campos inúteis legados, mas sim focar na simplificação e captura de dados assertiva logo no intake inicial.
