# Instruções - ui

## Responsabilidade
Módulo de interface.

Responsável por views, telas, forms, campos, menus, rotas, estados visuais, e contratos de frontend.

**Regra obrigatória:** Toda feature com impacto visual precisa ter frontend correspondente ou contrato visual documentado em docs/ui/VIEW_CONTRACT.md.

## O que pode fazer
- Desenvolver a interface de usuário.

## O que não pode fazer
- Implementar código fora do padrão de views documentado.
