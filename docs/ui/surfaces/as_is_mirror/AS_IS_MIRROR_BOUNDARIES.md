# As-Is Mirror Boundaries

## As-Is Mirror Board:
- **visualiza** o fluxo atual espelhado;
- **mostra** etapas, handoffs, evidências, gaps e incertezas;
- **apoia** entendimento do processo atual;
- **prepara** modelagem To-Be futura;
- **não executa** fluxo real nesta fase.

## Gap Tracker (Contexto):
- organiza lacunas em profundidade;
- pode alimentar overlays no As-Is Mirror.

## Source Intake (Contexto):
- organiza fontes e evidências;
- pode alimentar evidências vinculadas ao As-Is Mirror.

## Process Mirroring Intake (Contexto):
- visão agregada do piloto;
- pode listar mirrors e status geral.

## O As-Is Mirror Board NÃO DEVE:
- executar workflow;
- criar OS real;
- validar processo real;
- editar Markdown real;
- salvar em banco;
- chamar API;
- coletar fonte real;
- armazenar PII;
- desbloquear REAL-SRC-002;
- desbloquear CAP-VAL-002;
- criar runtime.
