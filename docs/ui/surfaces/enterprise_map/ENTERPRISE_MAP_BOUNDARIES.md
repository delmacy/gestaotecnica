# Enterprise Map Boundaries

## Escopo do Enterprise Map:
- Consolida representações sintéticas.
- Mostra relações entre componentes corporativos.
- Permite trocar perspectivas.
- Conecta conceitos já modelados (capabilities, sistemas, etc.).

## O que NÃO é o Enterprise Map:
- Não coleta arquitetura real.
- Não é um CMDB (Configuration Management Database).
- Não é catálogo real de aplicações.
- Não é organograma.
- Não é ferramenta de inventário operacional.
- Não é runtime executável.
- Não é editor de processos.
- Não altera capabilities reais.
- Não cria sistemas reais.
- Não registra owners reais na base de dados.
