# Enterprise Map Interaction Rules

## Permitido:
- Selecionar blueprint sintético.
- Trocar perspectiva.
- Filtrar node type, domain, readiness e data source mode.
- Selecionar node ou relationship.
- Destacar vizinhança de relações.
- Centralizar node e aplicar zoom local.
- Ocultar camada localmente.
- Visualizar detalhes no painel.
- Abrir rota relacionada no painel de detalhes.
- Limpar filtros.

## Proibido:
- Salvar posições de nodes na base.
- Persistir o mapa gerado.
- Criar node real no DB.
- Editar capability real.
- Editar processo real.
- Registrar owner real.
- Importar fonte real.
- Exportar dados reais.
- Chamar rotas de API não mockadas.
- Alterar workspace ou configurações de proxy.
- Executar workflow.
- Instalar capability de fato.
- Desbloquear recursos do Grupo D.
