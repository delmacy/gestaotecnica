# Gap Tracker Boundaries

## Gap Tracker:
- organiza lacunas de coleta e validação;
- classifica impacto, severidade e risco;
- exibe fontes/evidências faltantes em mock;
- relaciona gaps com observações e capabilities;
- prepara validação real futura;
- não resolve gap real nesta fase.

## Source Intake:
- organiza fontes e evidências;
- pode alimentar gaps derivados;
- não substitui o Gap Tracker.

## As-Is Mirror:
- superfície futura para visualizar o processo espelhado;
- pode consumir gaps para indicar incertezas no mapa As-Is.

## Gap Tracker não deve:
- fazer upload real;
- armazenar PII;
- ler arquivo real;
- editar Markdown real;
- salvar em banco;
- chamar API;
- validar processo real;
- desbloquear REAL-SRC-002;
- desbloquear CAP-VAL-002;
- criar runtime.
