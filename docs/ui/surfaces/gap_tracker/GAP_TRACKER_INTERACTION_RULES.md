# Gap Tracker Interaction Rules

## Interações permitidas:
- selecionar gap;
- filtrar por status;
- filtrar por severidade;
- filtrar por tipo;
- filtrar por owner_role;
- visualizar fontes requeridas;
- visualizar evidências ausentes;
- visualizar risco;
- visualizar next action;
- visualizar observações relacionadas;
- visualizar capabilities relacionadas;
- simular alteração de review decision local;
- simular marcação de gap como reviewed;
- limpar filtros.

## Interações proibidas:
- upload real;
- download real;
- criar fonte real;
- coletar PII;
- editar Markdown real;
- salvar alteração;
- gravar banco;
- chamar API;
- coletar arquivo;
- validar processo real;
- fechar gap real;
- desbloquear CAP-VAL-002;
- desbloquear REAL-SRC-002;
- criar runtime.
