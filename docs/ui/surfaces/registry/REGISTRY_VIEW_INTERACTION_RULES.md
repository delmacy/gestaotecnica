# Registry View Interaction Rules

## Interações Permitidas

- Buscar item textualmente.
- Filtrar por tipo (type).
- Filtrar por status.
- Selecionar um item da lista.
- Abrir painel de detalhe do item selecionado.
- Visualizar dependências (depends_on, used_by).
- Visualizar documentos associados (links).
- Copiar slug ou referência.
- Limpar filtros.

## Interações Proibidas

- Editar item.
- Salvar mudança.
- Deletar item.
- Instalar capability.
- Publicar registry.
- Versionar registry.
- Alterar workspace real.
- Criar ou alterar runtime.
