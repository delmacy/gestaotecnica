# Source Intake Visual Model

This component will be composed of:
1. Source Inventory List
2. Source Detail Panel
3. Evidence List Panel
4. Consent Status Panel
5. Sensitivity & Reliability Panel
6. Limitations Panel
7. Conflicts Panel
8. Gaps Panel

It strictly uses React local state (useState) and standard HTML elements for tabs/buttons, to adhere to the strict no-new-dependencies rule.
