# Adaptacao: Secao Tecnica

Esta pasta concentra a primeira adaptacao real da plataforma.

Ela ensina o core e os modulos reutilizaveis a operar com o vocabulario,
tipos, papeis, filas, workflows e templates da Secao Tecnica.

Esta camada nao deve implementar persistencia pesada nem regras internas
profundas dos modulos. A responsabilidade dela e configurar o comportamento
local do workspace.
